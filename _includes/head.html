{%- comment -%} Local override of Minimal Mistakes' _includes/head.html. The ONLY change from upstream is pinning Font Awesome to a major version. The theme ships `@latest`, an unpinned URL — which is how this site moved from FA 5 to FA 7 with no change on our side. Across majors Font Awesome renames and retires icons (fa-twitter became fa-x-twitter in 7), so `@latest` can break icons at any time. Pinning here rather than adding a second in head/custom.html keeps a single Font Awesome download; layering a pinned tag on top of the theme's made the browser fetch both stylesheets and both webfont files. Because this file shadows the theme's, upstream changes to head.html will not reach this site — re-sync it when bumping the theme.
